# 공통 오프닝 v3 — HUMAN의 행복한 내일

128초 / 1280×720 / 24fps / H.264 / 무음 시안.

HUMAN 홍보실이 제작한 것처럼 발랄한 픽셀 광고로 시작한다. 채팅창, 자동 채점, AGI 연결, 서류 가방 퇴장, 기본소득 코인과 축포를 직접 애니메이션으로 구성했다. 배경과 모니터가 함께 줌아웃된 뒤 전원이 꺼지고, 인간 측의 이야기가 나온다. 정지 그림 페이드인만으로 진행하지 않는다.

- 0~64초: 2024 대화형 AI 일상화 → 2026 시험 부정행위 → 2030 AGI → 회사별 AGI 통합/HUMAN → 노동 해방 홍보.
- 64~71초: 기록실로 카메라가 빠지고 전원 버튼을 눌러 광고를 끈다.
- 71~121초: 선택권·기록 상실 → 러다이트의 저항 → 보존관 고용 → AI 비용을 아낀다는 혼잣말 → 두 진영의 기록 처리 → 학생에게 질문. 중3이 이해할 일상 표현을 사용하며, 원래 기록 보관 후 HUMAN 기록을 변조하는 순서를 보여 준다.
- 115~128초: 제목·1910~1980 기록실·학생에게 넘어가는 이야기.

더빙·음악은 추가하지 않았다. 학생들이 소리를 들을 수 없는 환경에서도 자막과 화면만으로 이해하는 버전이다. 얼굴·옆얼굴·반사상·조각상은 사용하지 않았다. 기존 공통 v1/v2와 러다이트 v10은 보존한다. 게임에는 연결하지 않았다.

## 연표

2024는 서비스 최초 출시가 아닌 일상화 표현이다. ChatGPT는 2022년, Claude·Gemini는 2023년에 공개됐다. 2026 시험 사태와 2030 AGI는 게임의 가상 연표다. 홍보의 ‘해방’은 HUMAN의 주장이고 인간 파트가 반박한다. 상세 콘티와 공식 출처는 `docs/OPENINGS.md` 참조.

## 제작

- 코드: `scripts/openings/render-common-propaganda-v3.swift`
- 배경: 내장 image_gen으로 신규 생성한 두 PNG. 프롬프트 전문과 결과 ID는 `assets/openings/common-propaganda-v3/image-prompts.json`.
- 글꼴: Galmuri11 / Galmuri11-Bold, macOS 사용자 Fonts 폴더에 설치된 폰트 사용.
- 새 배경은 `assets/openings/common-propaganda-v3/`에 보관. 이전 영상 자산에 의존하지 않는다.
- macOS AVFoundation/CoreGraphics/CoreText로 출력. `--stills` 옵션은 검수용 정지 프레임만 만든다.

## 검수

최종 MP4의 128초·1280×720·24fps·오디오 트랙 0개를 확인했다. 후반부 대사, 비용 비교, 원래 기록 보관 후 변조 순서, 마지막 제목을 실제 영상의 12개 프레임으로 검수했다.
