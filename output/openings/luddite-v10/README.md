# 러다이트 전체 오프닝 v10 — 서버에서 종이로 부드러운 복귀

79초, 1280×720, 24fps. 무음판 및 경고음판. 현재 최종 영상만 output에 보관한다.

- 저장 완료 후 서버를 잡던 화면이 종이로 갑자기 컷 전환되던 부분을 수정했다.
- 전체 영상 약 21.1~22.25초에 카메라 위치와 확대율을 함께 연속적으로 바꿔, 서버에서 아래의 종이로 내려온다.
- 이동 시작·끝의 속도와 가속도가 0이 되는 곡선을 사용해 급출발과 급정지를 줄였다.
- 카메라가 도착한 뒤인 약 22.35초에 벨트와 롤러를 재가동하고, 약 23초부터 파쇄 조각이 나온다.
- ‘0·1 변환 → 서버 저장 완료 → 종이 파쇄’ 순서는 유지했다.
- 최초 제작은 14~25초만 렌더해 v9와 연결했다. 현재 렌더러는 이전 MP4 없이 전체 79초를 직접 렌더한다.
- 중간 영상은 /private/tmp에 저장하며 원본 이미지는 `assets/openings/`에서 재사용한다.
- 제작 코드: scripts/openings/render-luddite-v10.swift. 재제작 자산은 `assets/openings/`의 luddite-v8, luddite-v9, conveyor-motion-test-v1, record-extraction-test-v1에 있다.
- 게임 연결·배포·커밋은 하지 않았다.
