# 2030 — 현대문학사 데이터 점령전

**영상 콘티 편집** · [엔딩 3편](docs/엔딩-콘티.md) · [오프닝 3편](docs/영상-3편-콘티와-대사.md)

Phaser 3 + JavaScript + Vite로 만든 탑다운 픽셀 게임입니다.
싱글플레이와 **최대 30명 교실 멀티플레이**를 지원합니다. 실시간 연결은
Cloudflare Workers + SQLite 기반 Durable Objects + WebSocket을 사용합니다.
Firebase는 새 게임에서 사용하지 않습니다.

**배포 주소:** https://lit-war-multiplayer.gugeo.workers.dev (2026-11-22 배포, `npm run deploy`)

## 바로 실행

Node.js 22.12 이상을 권장합니다. 의존성을 처음 받거나 갱신할 때 `npm ci`를 실행하세요.

**미니게임만 확인:** `npm run dev`를 실행하고 터미널에 표시된 주소 뒤에 `/minigames.html`을 붙여 여세요. 시대와 미션을 직접 고르고 같은 문제를 반복할 수 있습니다. 이 페이지는 서버·교실 입장 없이 혼자 실행됩니다.

```sh
npm ci
npm run dev:multi
```

- 기존 `npm run dev`가 켜져 있으면 먼저 그 터미널에서 Ctrl+C로 종료합니다.
- `dev:multi`는 정적 빌드 후 Vite(5173)와 로컬 Cloudflare 런타임(8787)을 함께 켭니다.
- http://localhost:5173 을 **브라우저 창 두 개**에서 엽니다.
- **먼저 http://localhost:5173/teacher.html 에서 방을 엽니다**(`새 코드` 또는 직접 입력 + 교사 비밀번호). 학생은 교사가 연 방에만 들어올 수 있습니다.
- 각 창에서 TV 화면의 QR 링크(`/?room=코드`)를 열거나 `교실 입장` → 같은 방 코드, 서로 다른 닉네임으로 입장합니다.
- 방 코드는 영문/숫자 4~12자리, 닉네임은 한글/영문/숫자 등 1~12자입니다.
- 입장한 순서대로 인류유산 보존관(파랑)·러다이트(빨강)로 나뉩니다.
- 방향키/WASD 이동, 단말기·고장 난 곳 근처 E, 공격 중 감전 SPACE, 닫기는 ESC입니다.
- 숫자키 단축키: `1` 방해 공작, `2` 실시간 공격(공격권을 바로 쓰므로 **2를 두 번** 눌러야 출발, 2.5초 안에), `3` 함정(보존관만). 입력칸에 글자를 쓰거나 창·미니게임·오프닝이 열려 있으면 동작하지 않습니다.
- 휴대폰·태블릿은 왼쪽 아래 조이스틱으로 이동하고, 오른쪽 아래 버튼이 상황에 따라 접속·수리·⚡감전으로 바뀝니다.
  PC에서 터치 화면을 미리 보려면 주소 끝에 `?touch`를 붙입니다.
- 접속 관리에서 방을 나가면 기존 혼자 연습 모드로 돌아갑니다.
- 학생 화면([통합 시안 v2](docs/design/v2/README.md)): 위 띠(진영 단말기 표시·남은 시간·접속), 게임 화면 전체, 아래 띠(미션·행동 버튼·조작법). 크롬북 1366×768에서 게임이 화면 높이의 약 86%를 차지하고 스크롤이 없습니다. 보존관은 밝은 HUMAN 공식 단말기, 러다이트는 어두운 비인가 접속 단말기 틀이고 배치는 같습니다. 게임 위 가운데 알림 칸은 실시간 공격 배너가 우선이고, 없으면 오염 경보를 보여 줍니다. 오른쪽 위 점령 지도는 접전(10점 이내) 시대에 노란 테두리를 둡니다.
- 서버를 종료하려면 실행 터미널에서 Ctrl+C를 누릅니다.

로컬 테스트에는 Cloudflare 로그인과 유료 결제가 필요 없습니다.
`localhost`는 각 기기 자신을 뜻하므로 이 주소를 학생에게 보내서는 서로 연결되지 않습니다.
학생 크롬북에서 쓰려면 인터넷 배포가 필요합니다.

## 교사용 화면 · 교실 TV

`/teacher.html`(수업 관제 콘솔)에서 방 코드와 교사 비밀번호를 넣고 들어갑니다. 화면 디자인은 [통합 시안 v2](docs/design/v2/README.md)를 따릅니다: 왼쪽 상태·조작, 가운데 점수·시대 지도·학생 명단, 오른쪽 공격 중계·오염 기록·관제 로그.

- **처음 들어간 교사가 비밀번호를 정합니다.** 이후 교사 접속은 같은 비밀번호여야 합니다. 비밀번호는 해시로만 저장합니다.
- **학생은 교사가 연 방에만 입장합니다.** 교사가 한 번도 안 들어온 방 코드로 들어오면 "아직 열리지 않은 방" 안내가 나옵니다. 방 코드는 `새 코드` 버튼으로 헷갈리는 글자(0/O, 1/I/L) 없이 6자리로 만들 수 있습니다.
- **입장 안내(코드 + QR):** 학생 링크(`/?room=코드`) QR을 찍으면 방 코드가 채워진 입장 창이 열려 닉네임만 입력하면 됩니다. 교사 화면 왼쪽에 작은 QR과 `QR 크게 보기`·`코드 복사`가 있고, TV에는 시작 전 큰 QR, 진행 중에는 오른쪽 위 작은 QR이 늘 나옵니다.
- **학생 명단:** 진영별 두 열, **가나다순 고정**(미션 수가 바뀌거나 접속이 끊겨도 줄이 움직이지 않음). 끊긴 학생은 제자리에서 흐리게 `끊김`, 위에 `끊김 n명`. 퇴장은 이름 옆 `⋯` 메뉴 안에 있습니다.
- **접전 표시:** 한 시대에서 두 팀 점수 차가 10점(미션 하나) 이하면 노란 `접전` 표시. 완전 동점은 `동점`. 표시만 바뀌고 규칙은 그대로입니다.
- 교사가 방을 열면 `시작 대기`가 되고, 학생은 돌아다닐 수만 있고 단말기·공격·사보타주는 막힙니다.
- **🎬 오프닝 재생:** 시작 전에 누르면 학생마다 자기 진영 영상(보존관 83초 / 러다이트 79초)이 전체 화면으로 재생됩니다. 이 동안은 시간이 흐르지 않고 미션도 막힙니다. 교사 화면에 `n / m명 완료`가 나오고, **지금 접속한 학생이 모두 다 보면 `▶ 시작`이 켜집니다.** 영상이 안 끝나는 학생이 있으면 `기다리지 않고 시작`으로 바로 시작할 수 있습니다. `🎬 다시 재생`은 모두에게 처음부터 다시 틀어 줍니다. 다 본 학생은 새로고침해도 다시 보지 않고, 중간에 들어온 학생은 바로 영상을 봅니다. 학생은 방에 들어오면 대기 중에 자기 진영 영상을 미리 받아 두고, 아직 다 못 받았으면 학생 화면에 진행 막대가 나옵니다. 교사 화면 학생 명단에는 `⬇ 불러오는 중 40%` · `▶ 시청 중` · `👆 재생 버튼 대기` · `✓ 시청 완료` 같은 상태가 표시됩니다. 웹용 영상은 `public/openings/`(MP4 + WebM, 각 4MB 안팎)이며, 원본(`output/openings/`)을 고치면 아래 「다른 실행 / 검사」 위의 명령으로 다시 만듭니다.
- **시작(1~90분) / 멈춤 / 계속 / 종료 / 초기화.** 멈춤·종료 때는 열린 단말기 창이 닫히고 진행 중인 공격도 끝납니다. 시간이 다 되면 서버가 자동으로 종료합니다.
- 초기화는 점수·미션 수·권한·방해 공작을 0으로 되돌리고 팀 배정은 유지합니다.
- 시대별 점령 현황, 팀 합계, 학생 명단(접속 여부·미션 수·공격 중 표시·퇴장), 실시간 소식(권한 획득·침입·감전·방해 공작)을 보여 줍니다.
- **실시간 공격 중계:** 공격이 시작되면 교사 화면에 `⚡ 실시간 공격 중계` 패널이 열리고, 방어자 기록실 지도 위에서 두 학생의 움직임·감전·남은 시간을 보여 줍니다. 두 명이 화면에 함께 들어오도록 카메라가 따라가고, 동시에 여러 공격이 있으면 보던 중계를 끊지 않고, 끝나면 3초 결과를 보여 준 뒤 다음 공격으로 넘어갑니다(교사 화면은 탭으로 직접 바꿔 볼 수도 있음). 공격 중 위치는 원래 공격자·방어자 사이에만 오가던 것을 교사에게도 복사해 보내는 방식이라, 학생이 보내는 메시지 수(무료 한도 계산 기준)는 늘지 않습니다. 중계 화면(Phaser)은 첫 공격 때만 불러옵니다.
- **교실 TV(`/tv.html`, 보기 전용):** 교사 화면 오른쪽 위 `📺 TV 화면 열기`를 누르면 새 창으로 열리고 자동으로 접속합니다(교사 탭의 로그인 정보를 넘겨받음). 교실 TV 컴퓨터에서 따로 열면 방 코드와 교사 비밀번호를 한 번 입력합니다. 1920×1080 기준으로 만들어 어떤 화면에서도 비율을 유지한 채 맞춰 줄어듭니다. 상태에 따라 **입장 대기·오프닝**(큰 QR·코드·진영별 이름, 오프닝 시청 완료 수) → **진행 중**(진영 점수·남은 시간·줄다리기 막대·기록 보관소 지도·오염 경보·관제 로그) → **실시간 공격 중계**(실제 게임 화면, 남은 초, 감전 5칸, 결과) → **멈춤**(가림막)으로 바뀝니다. 예전 `teacher.html?tv` 주소는 TV 화면으로 넘어갑니다.
- **게임 화면 이탈 경고:** 오프닝·게임 진행 중에 학생이 게임 탭을 1.5초 넘게 벗어나면(다른 탭·창으로 전환, 창 최소화) 교사 화면과 TV 아래쪽에 **빨간 `🚨 수업 이탈` 띠**(이름과 벗어난 시간)가 뜨고, 그 학생이 돌아올 때까지 계속 떠 있습니다. 교사 명단 줄도 빨갛게 `🚨 수업 이탈 0:12`, 관제 로그에 `🚨 ○○ 수업 이탈 (n번째)`가 남습니다. 이유(다른 창·창 최소화·전체 화면 해제)와 상관없이 교사·TV에는 `수업 이탈`로만 표시합니다. 돌아오면 학생 화면에 `n번째, ○초` 안내가 나옵니다. 브라우저는 이동을 막을 수 없으므로 감지만 하며, 게임 화면이 보이는지 여부만 보내고 어디로 갔는지는 알 수 없습니다. 
- **전체 화면 필수:** 학생이 `교실 입장`을 누르면 전체 화면이 켜집니다(브라우저는 클릭이 있어야 허용). 오프닝·게임 진행 중에 전체 화면이 아니면 가림막이 게임과 미니게임 창을 덮고 조작이 막히며, `⛶ 전체 화면으로 돌아가기`를 눌러야 계속합니다. 크롬에서는 ESC를 **길게** 눌러야 전체 화면이 꺼집니다. 전체 화면을 끈 것도 `수업 이탈`로 경고하며, 새로고침·재접속은 전체 화면이 저절로 풀리므로 시작·접속 직후 10초는 세지 않습니다(가림막은 바로 나옴). 전체 화면을 지원하지 않는 기기(아이폰 사파리 등)는 가림막 없이 플레이합니다. 학생 화면 위 `⛶ 전체 화면` 버튼도 있습니다. 운영체제 키(런처·창 전환)까지 확실히 막으려면 학교 크롬북 관리 도구(탭 잠금 기능)가 필요합니다.
- **글꼴:** 숫자·코드는 갈무리11, 문장은 Pretendard. 둘 다 게임에 직접 포함되어 학교망에서 CDN이 막혀도 그대로 보입니다(라이선스: `src/shared/fonts/`).
- 학생 화면 HUD에는 남은 시간과 상태(대기·멈춤·끝)가 나옵니다.

오프닝 웹용 영상 다시 만들기(Cloudflare 정적 파일은 한 개 25MB 제한):

```sh
for n in guardian:guardian-v1/guardian-v1-sound luddite:luddite-pixel-v12/luddite-pixel-v12-sound; do
  ffmpeg -y -i output/openings/${n#*:}.mp4 -c:v libx264 -preset slow -crf 27 -pix_fmt yuv420p -c:a aac -b:a 96k -movflags +faststart public/openings/${n%%:*}.mp4
  ffmpeg -y -i public/openings/${n%%:*}.mp4 -c:v libvpx-vp9 -crf 36 -b:v 0 -row-mt 1 -c:a libopus -b:a 96k public/openings/${n%%:*}.webm
done
```

## 다른 실행 / 검사

```sh
npm run dev             # Vite만 실행. 혼자 연습 가능
npm run build           # 정적 결과: build/
npm run dev:server      # build/가 있는 상태에서 로컬 서버만 실행
npm run preview         # 정적 빌드 미리보기만. API 프록시는 없음
npm test                # 36개 단위 테스트
npm run test:multiplayer # 8787 서버가 실행 중일 때 실제 WebSocket 통합 검사
npm run check:worker    # 업로드/배포 없이 Worker dry-run
```

Vite는 `/api` 요청을 8787로 프록시합니다. 로컬 서버 자체 주소
http://127.0.0.1:8787 에서는 마지막 `build/` 결과와 WebSocket을 함께 제공합니다.

## 게임 규칙 (규칙표 가안 반영)

- **각자 자기 기록실:** 학생마다 같은 모양의 방을 따로 갖고 혼자 돌아다닙니다. 평소에는 위치를 서버로 보내지 않습니다.
- **연도별 단말기 8개:** 1910~1980년대 기록실에 단말기가 하나씩 있습니다. 배선·주파수·키워드 기억·오답 격추·작가 신원 확인·시대 분류 필터·연도순 책 꽂기·엔진 정렬·데이터 업로드·진위 판별·우편 배달·요리 순서·키워드 낚시·퍼즐 조각 중 무작위 미션을 냅니다. 요리 순서는 1930년대 「동백꽃」 전용입니다. 완료하면 해당 시대 팀 점수 +10.
- **진영:** 인류유산 보존관(파랑, GUARDIAN)과 러다이트(빨강, LUDDITE)로 입장 순서에 따라 반반 배정. 팀 이름·역할 문구는 `src/prototype/teams.js` 한 곳에서 바꿉니다. 같은 기기·같은 닉네임으로 다시 들어오면 진영·미션 수·권한이 유지됩니다.
- **점령 현황:** 시대마다 점수가 높은 팀이 그 시대를 점령합니다.
- **➜ 추천 단말기:** 게임 진행 중 학생마다 "지금 한 판 하면 가장 도움이 되는" 단말기 하나를 화살표로 알려 줍니다. 단말기가 화면 안에 있으면 그 위에 `추천` 화살표, 밖에 있으면 화면 가장자리에서 그쪽을 가리킵니다. 점령 지도 칸에 흰 테두리, 아래 상태 줄에 이유(예: `5점 차로 밀려요 · 한 판이면 역전`)가 나옵니다.
  - 우선순위: ① 우리 팀이 10점 이하로 지는 시대 → ② 더 많이 지는 시대 → ③ 동점(0:0 포함) → ④ 10점 이하로 앞서는 시대 → ⑤ 그 밖. 같은 순위 안에서는 무작위라 팀원이 여러 단말기로 흩어집니다.
  - 한 번 정한 추천은 그 학생이 미션을 하나 끝내거나, 그 단말기가 고장·바리케이드로 막히거나, 이미 우리 팀이 앞서게 됐는데 더 급한 곳이 있을 때만 바뀝니다(화살표가 자꾸 돌지 않도록).
  - 점수는 원래 받는 정보로 학생 화면에서 계산하므로 서버 메시지가 늘지 않습니다. 시작 전·멈춤·공격 중에는 숨깁니다. 규칙은 `src/prototype/recommend.js`.
- **미션 5개마다 진영별 권한, 10개마다 실시간 공격권:** 10번째 미션에는 두 권한이 각각 생깁니다. 보존관은 현재 바리케이드, 러다이트는 단말기 고장을 사용할 수 있습니다.
- **사보타주(비동기):** 상대 진영 학생 한 명이 랜덤으로 정해지고, 보존관은 🚧 통로 바리케이드를, 러다이트는 💥 단말기 고장을 설치합니다.
  - 바리케이드: 그 시대 방의 출입구를 막음. 120초 뒤 자동 해제 또는 수리.
  - 고장: 그 단말기에서 미션 불가. 수리해야 다시 사용.
  - 한 방에 바리케이드 최대 3개 또는 고장 최대 1개. 상대가 접속해 있지 않아도 걸 수 있습니다.
- **수리 미니게임(연대순 복구):** 서로 다른 시대의 작품 카드(바리케이드 3장, 고장 4장)를 발표 순서대로 누릅니다. 틀리면 처음부터.
- **🪤 함정(보존관):** 내 단말기 하나를 언제든 함정으로 지정(HUD `🪤 함정` 버튼). 러다이트가 단말기 고장으로 그곳을 고르면 고장은 실패하고 함정 주인이 그 러다이트 방으로 즉시 반격 공격(공격권 소모 없음). 주인이 접속해 있지 않거나 공격 중이면 10점 자동 탈취.
- **⚠️ 오염 경보(1분):** 교사 화면 버튼 또는 남은 10분 시점 자동 1회(수업이 20분 미만이면 절반 시점). 경보 중 러다이트는 미션 완료마다 미끼 1개(진짜 기록의 시대·작가 칸을 다른 값으로 바꿔 보존관 방에 심기, 성공 +20, 진짜 값을 고르면 실패). 보존관은 🧪 오염된 단말기에서 바른 값을 골라 정화(+20). 양쪽 모두 기회는 한 번이고, 결과 화면은 항상 진짜 기록으로 끝납니다. 교사 화면 '오염 기록'에 가짜→진짜가 남습니다.
- **실시간 공격(15초):** 지금 접속 중인 상대 진영 학생의 방으로 들어갑니다. 공격자는 가까이 붙어 <kbd>SPACE</kbd>로 감전, 방어자는 도망.
  - 감전 1회: 방어자 0.5초 이동 불가, 공격자 1.4초 충전 중 이동 불가, 상대 팀이 가장 강한 시대에서 5점을 빼앗음.
  - 감전 쿨타임 1초, 감전이 풀린 뒤 2초 무적, 공격 1회당 최대 5번.
  - 공격받는 학생의 단말기 창은 강제로 닫힙니다. 끝나면 공격자는 원래 자리로 돌아갑니다.
  - 공격할 상대가 없으면 공격권은 그대로 남습니다.

규칙 숫자는 `server/RoomEngine.js`의 `RULES`에서 바꿉니다.

## 서버 사용량 (무료 플랜 기준)

- 서버로 가는 메시지는 미션 조작, 15초마다 ping, **실시간 공격 중의 이동**뿐입니다.
- Durable Objects 무료 한도는 하루 요청 100,000건이고, 학생이 보내는 WebSocket 메시지 20개가 1건으로 계산됩니다. 한도는 한국 시간 오전 9시에 초기화됩니다.
- 30명·45분 수업 1회 예상치는 수천 건 수준입니다. 배포 후 Cloudflare 대시보드에서 실제 사용량을 확인하세요.

서버는 클라이언트의 +10 요청을 받지 않습니다. 임무 상태를 서버에 두고 각 명령을 검증해
점수와 공격권을 줍니다. 단말기 접속·수리는 학생이 알려 준 위치가 그 단말기 근처인지 검사합니다
(혼자 다닐 때는 위치를 보내지 않으므로 위치 조작까지 막지는 않습니다). 실시간 공격 중의 이동은
속도·좌표·경로 충돌(상대 방의 바리케이드 포함)을 검사하고, 감전은 서버가 아는 두 위치로 판정합니다.

Durable Object 하나가 방 하나를 담당합니다. 팀 점수, 학생별 프로필(진영·미션 수·권한·방해 공작),
진행 중인 실시간 공격을 저장하고, 열린 미션 창과 공격 중 위치는 WebSocket attachment로 휴면 복원합니다.
빈 방도 점수는 유지되므로 새 수업을 0점으로 시작하려면 **새 방 코드**를 사용하세요.

## 인터넷 배포

Cloudflare에 로그인한 상태에서 아래를 실행하면 같은 주소로 갱신됩니다.

```sh
npx wrangler login
npm run deploy
```

`lit-war-multiplayer`라는 별도 Worker에 게임 정적 파일과 API를 함께 배포하는 구성입니다.
기존 Cloudflare Pages 및 기존 도메인은 변경하지 않습니다. Worker가 반환하는 HTTPS 주소를
학생들에게 공유하면 됩니다. 학교 네트워크에서 WSS 연결과 2대 동시 이동을 먼저 검사한 후
30명 검증으로 늘리세요. 무료 플랜 한도 충족 여부는 실제 수업 사용량을 측정해야 합니다.

로그인/배포는 사용자가 원하는 Cloudflare 계정으로 진행해야 하며 비밀번호/API 토큰을
저장소나 채팅에 적지 않습니다. `.wrangler/`, `.dev.vars`는 Git에서 제외합니다.

## 규칙표에서 아직 정할 것

- 러다이트 미션은 문구만 '원본 탈취'로 다르고 방식은 같습니다. 전용 장치는 오염 경보의 미끼 심기입니다.
- 시대별 줄다리기 바와 기존 점수 비교 중 최종 방식: 현재 점수 비교를 임시로 유지합니다.
- 보호막: 아직 활성화하지 않았습니다. 함정은 상시 1개로 확정해 반영했습니다.
- 시범 수업 시기와 대상 반.

## 다음 단계의 한계

- 방 코드는 접속 구분자이며 학생 인증이 아닙니다. 교사가 연 방의 코드를 아는 사람은 입장할 수 있습니다.
- 자동 정답 입력 같은 치팅까지 방지하지 않습니다. 지금은 범위/정답/중복 보상 검증 단계입니다.
- 교사 화면은 가안입니다. 학생 계정, 수업 결과 리포트(오답률 등)는 아직 없습니다.
- 재접속 시 개인 임무/위치를 복구하려면 별도의 학생 세션 지속 정책이 필요합니다.
- 전송량과 지연은 배포 후 측정해야 합니다. 필요 시 여러 위치를 묶어 전송하는 방식으로 최적화합니다.
- 에셋 교체 시 24×32 캐릭터 프레임과 발 충돌체(14×11), 서버 공용 충돌 판정을 함께 조정합니다.
