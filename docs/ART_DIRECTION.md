# 세계관 영상·아트워크 제작 원칙

## 얼굴을 보여 주지 않는다 — 선생님 확정

- 인물의 정면 얼굴과 옆얼굴이 드러나지 않게 한다.
- 뒷모습, 얼굴이 완전히 돌아간 구도, 얼굴 특징이 없는 먼 실루엣, 손과 사물로 사람의 존재를 표현한다.
- 유리·거울·금속의 반사상, 조각상·흉상, 그림·사진·포스터, 화면 속 이미지에도 같은 원칙을 적용한다.
- 얼굴을 흐리거나 검열하는 방식보다 처음부터 얼굴을 보이지 않는 자연스러운 구도를 사용한다.
- 사람의 존재와 행동은 유지한다. 얼굴을 없애기 위해 장면의 의미·의상·상징·기존에 선택한 화풍까지 바꾸지 않는다.
- 결과 검수 때 전경뿐 아니라 배경 인물과 반사상도 확인한다.

이 원칙은 세계관 영상과 관련 아트워크에 적용한다. 기존 게임 캐릭터나 UI를 변경하라는 요구로 확대하지 않는다.

## 공통 오프닝 새 방향 — 선생님 요청 (2026-11-19)

- 공통편 v3는 발랄한 픽셀 아트의 HUMAN 홍보 영상으로 시작한다. 민트·노랑·코랄, 갈무리, 게임 UI와 빠른 사물 애니메이션을 사용한다.
- 홍보 영상을 물리적으로 끈 뒤 인간 측 의견이 나온다. 밝은 선전과 어두운 인간 기록실의 대비를 만든다.
- 얼굴 비노출·무음 이해 원칙은 그대로 유지한다.
- 아래 회화적 스타일은 기존 v1/v2와 러다이트 영상의 방향으로 보존한다. v3 픽셀 방향을 막는 제한이 아니다.

## 기존 영상에서 유지할 표현

- 선생님이 선택한 질감 있는 영화적 게임 아트워크, 차가운 서버와 따뜻한 인간 자료의 대비.
- 갈무리 자막과 소리 없이 이해되는 화면.
- 정형적인 도형·학습만화 느낌을 피하고, 실제 아트워크의 공간·빛·물성으로 의미를 전달한다.
