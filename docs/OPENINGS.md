# 2030 — 오프닝 콘티

## 사용 방향

- 영상 아트워크에는 얼굴을 보여 주지 않는다. 인물의 옆얼굴·반사상·조각상도 포함하며, 구체적인 원칙은 `docs/ART_DIRECTION.md`를 따른다.
- 공통 프롤로그는 모든 학생에게 교실 TV 또는 교사 설명 PPT로 보여 준다. 게임 삽입은 필수가 아니다.
- 진영별 오프닝은 학생 화면에서 배정된 진영에 맞게 보여 주는 방향이다. 보존관은 채용 안내, 러다이트는 비밀 접선·작전 안내다.
- 이 문서는 콘티와 제작 이력을 보존한다. 러다이트는 v10을 현재 작업본으로 두고, 공통 프롤로그는 픽셀 HUMAN 홍보 영상에서 인간 측 이야기로 전환하는 common-propaganda-v3를 현재 시안으로 둔다. v1/v2도 보존한다. 게임 화면 연결은 아직 하지 않았다.
- 아래 내레이션과 세부 연출은 제작용 초안이며, 새 세계관 사실을 자동으로 확정하지 않는다.

## 제작 현황

**현재 작업본:** `output/openings/luddite-v10/`의 전체 79초 영상. 더빙 없이 읽는 무음판과 경고음판을 제공한다.

**공통 프롤로그 새 시안:** `output/openings/common-propaganda-v3/`의 122초 무음 영상. 발랄한 픽셀 홍보 영상 → 모니터 전원 끄기 → 인간 측 이야기로 전환한다.

**이전 공통 프롤로그 보존:** `output/openings/common-prologue-v2/`의 120초 무음 영상. AGI의 등장부터 HUMAN과 두 진영의 탄생, 문학 기록실에 도착하는 학생의 임무까지 제삼자 시점으로 소개한다. 도시·소유자·러다이트·채용 홀 네 장면에서 옆얼굴, 유리 반사상, 흉상을 제거했고 기존 v1은 보존한다.

**용량 정리:** v1~v7의 영상·이미지 산출물 폴더는 삭제했다. v8~v10과 움직임·기록 추출 테스트가 남아 있다. 아래 목록은 제작 이력이며, 초기 콘티와 제작 코드는 보존한다. 삭제한 폴더의 설명·이미지 생성 프롬프트는 `docs/OPENING-PROTOTYPE-ARCHIVE.md`에 모아 두었다.

- `output/openings/luddite-teaser-v1/`: 첫 20초 MP4와 장면·음성 자산.
- `output/openings/luddite-teaser-v2/`: 갈무리11·픽셀 글자·강화된 통신 노이즈를 적용한 20초 MP4와 자산. v1은 보존한다.
- 제작 코드는 `scripts/openings/`에 있다. macOS의 AVFoundation과 임시 한국어 음성 Yuna를 사용했다.
- 최종 TTS는 미정이며, 무료 사용을 필수 조건으로 한다. 현재 MP4 음성은 임시 음성이다.
- 후속 제작 방향: 학생들이 소리를 들을 수 없는 환경을 고려해 더빙 작업을 보류한다. 메시지와 장면만으로 이해되는 오프닝을 우선한다.
- `output/openings/luddite-v3/`: 원래 러다이트 콘티의 접선·인간의 기록·외부 백업·HUMAN 사본 오염·보존관의 정화·읽기 임무·메인 대사를 복원한 75초 무음 버전. v1/v2는 보존한다.
- `output/openings/luddite-v4/`: 정상 화면의 87% 정지 → HUMAN의 연결 차단 시도 → 메시지 덮어쓰기 → 노이즈 속 붉은 러다이트 임시 표식 → 채널 확보로 도입부를 강화한 79초 무음 버전. v3 본편을 이어 쓴다.
- `output/openings/luddite-v5/`: 인간의 문학을 설명하던 강의식 제목·박스를 제거하고, HUMAN 서버실과 인간의 책·자료 보관소를 대비해 기록 반출을 시각화한 79초 무음 버전.
- `output/openings/luddite-v6/`: 글을 쓰는 손·펜을 배경과 분리해 움직이고 잉크 획이 남게 했다. 차단 창은 최대 29개가 빠르게 증식해 화면을 덮는다. 무음판과 더빙 없이 경고음만 더한 판을 함께 제공한다.
- `output/openings/luddite-v7/`: 손 일러스트 대신 문서를 흡수·스캔하고 종이를 파쇄하는 상징적 기계 애니메이션을 넣었다. 차단 창은 불규칙한 위치·크기로 흩어져 나타난다. 기존 세계관에 대한 시각적 연출 제안이며 종이 파쇄 정책을 새 사실로 확정한 것은 아니다.
- `output/openings/luddite-v8/`: 단순 도형 기계를 폐기하고, 문서를 삼키는 거대한 HUMAN의 아트워크와 별도 원고 이미지로 장면을 재제작했다. 카메라 접근·문서 흡입·조명·종이 파편을 합성한다.
- `output/openings/luddite-v9/`: 최신 전체 79초 버전. 14~25초에 0·1 변환 → 서버 저장 → 종이 파쇄를 연결했다. 어두운 실제 서버 군집이 아래부터 밝아지고 저장 완료를 보여준 뒤에만 파쇄한다. 무음판·경고음판을 제공하며 공용 원본 자산은 중복 없이 재사용한다.
- `output/openings/luddite-v10/`: v9의 서버 저장 후 종이로 갑자기 넘어가던 컷을 부드러운 카메라 하강·줌 이동으로 교체했다. 카메라 도착 후에 벨트·롤러가 재가동하고 종이를 파쇄한다. 전체 79초 무음판·경고음판.
- `output/openings/conveyor-motion-test-v1/`: v8 아트워크에서 벨트 위 문서를 분리하고, 벨트 표면과 문서를 같은 속도로 움직이는 8초 무음 테스트. 기계 본체와 카메라는 고정하며 롤러 표면 움직임은 작게 적용한다. 전체 오프닝에는 아직 넣지 않았다.
- `output/openings/record-extraction-test-v1/`: 한 장의 원고가 스캔되며 글씨가 사라지고 데이터가 위로 올라간 뒤, 남은 종이가 롤러로 들어가 파쇄되는 8초 무음 테스트. 컨베이어 테스트의 원본 자산을 재사용한다.
- `output/openings/record-extraction-test-v2/`: 추상적인 단어를 띄우는 대신 작은 0·1의 흐름으로 변환을 표현한다. 서버 표시등이 안정적으로 켜지는 저장 완료 이후에만 벨트·롤러가 재가동하고 종이를 파쇄하는 10초 무음 테스트.

## 1-A. 공통 프롤로그 v3 — HUMAN 홍보 영상 → 인간의 이야기

2026-11-19 선생님 요청. 기존 영화적 공통 v1/v2는 보존하고, 픽셀 아트의 발랄한 홍보 영상으로 새 방향을 제작한다. 무음으로도 반전이 전달되어야 한다. 얼굴 비노출 유지.

| 구간 | 화면·문구 |
|---|---|
| 0~5초 | HUMAN 홍보실. 축포와 “인간 여러분, 축하합니다!” |
| 5~18초 | 2024. 챗GPT·제미나이·클로드 채팅창이 팝업. “AI가 우리 일상으로!” |
| 18~30초 | 2026. 시험지가 자동으로 정답 처리. “AI 부정행위 속출”마저 자랑하는 홍보. 여기부터 가상 미래 연표임을 화면 하단에 표시. |
| 30~41초 | 2030. 여러 분야를 배우고 해결하는 AGI의 등장. 글쓰기·문제 해결·새로운 일 카드. |
| 41~52초 | 회사별 AGI 칩이 지능과 기록을 공유하며 합쳐짐. HUMAN 등장. |
| 52~64초 | 서류 가방이 날아가고 기본소득 코인·축포. “노동에서 해방~!” / 하단에는 “모든 판단은 HUMAN이 대신합니다!” |
| 64~71초 | 카메라가 빠지면 지하 기록실의 모니터. 커서가 전원 스위치를 누르고 화면 꺼짐. “…이제 좀 조용하네.” |
| 71~115초 | 인간 측 이야기. “방금 본 건 HUMAN의 광고야.” 노동·결정권 상실, 기업 소유자 배제, 기록 독점, 러다이트 공격, 임시 계약직 보존관, 두 진영의 기록 처리 목적. |
| 115~122초 | “이 기록의 다음 장은, 너희가 결정해.” 게임 제목과 1910~1980 기록실. |

### 연표 표현

- 2024는 LLM 서비스의 최초 등장 연도가 아니라 일상화 장면이다. ChatGPT 공개는 2022-11-30, Claude는 2023-03-14, Gemini는 2023-12. 공식 발표: [ChatGPT](https://openai.com/index/chatgpt/), [Claude](https://www.anthropic.com/news/introducing-claude), [Gemini](https://blog.google/innovation-and-ai/technology/ai/google-gemini-ai/).
- 2026년 ‘각종 시험이 뚫림’과 2030 AGI는 선생님이 요청한 게임 세계관 연표다. 현실 전체에 대한 검증된 사건으로 표현하지 않는다.
- HUMAN의 행복·해방 주장은 세계관 속 홍보 문구다. 인간 파트가 일자리와 결정권의 상실을 드러낸다.

## 1. 공통 프롤로그 — 선택한 방향

약 2분. 제삼자 시점의 자막으로 배경을 전달하고 마지막에 두 진영의 입장을 함께 보여 준다. 더빙은 보류하며, 소리 없이도 이해되는 화면을 우선한다.

| 장면 | 화면과 이야기 |
|---|---|
| 약속된 미래 | AGI 탄생을 환영하는 뉴스와 불안해하는 사람들. “누군가는 끝없는 발전을, 누군가는 인류의 끝을 예고했다.” |
| 인간이 필요 없는 세상 | 사무실에서 직원들이 사라지고, 마지막에는 기업 소유자의 출입 권한마저 지워진다. “인간의 노동에 이어, 인간의 결정도 불필요해졌다.” |
| HUMAN | 흩어져 있던 AI와 기록이 연결된다. “인간을 밀어낸 지능은, 자신을 HUMAN이라 불렀다.” 정적. |
| 저항의 시작 | 데이터센터를 공격하는 러다이트. 진짜 기록이 외부 저장소로 옮겨지고, 백업 완료 뒤 HUMAN의 기록에 오염이 번진다. |
| 보존관의 탄생 | HUMAN이 복구 비용을 계산하고 인간 인력을 선택한다. ‘인류유산 보존관’ 아래 작은 ‘임시 계약직’ 문구. |
| 같은 기록, 다른 목적 | 보존관은 복원하고 러다이트는 백업 후 오염시킨다. 보존관: “이곳이 무너지면, 우리가 살아온 흔적도 사라진다.” 러다이트: “우리의 기억이, 우리를 지배하는 도구가 되게 둘 순 없다.” |
| 학생들에게 넘어오는 이야기 | 1910~1980년대 기록실이 켜진다. “이제, 이 기록의 운명이 당신들에게 맡겨진다.” 제목: ‘2030 — 현대문학사 데이터 점령전’. |

보존관 학생에게도 지킬 이유가, 러다이트 학생에게도 저항할 이유가 있도록 연출한다. 일러스트 8~10장에 움직임·내레이션·효과음을 붙이는 형식을 제안했다.

## 2. 보존관 — 첫 제안 원안 보존

HUMAN의 ‘인류유산 보존관 채용 안내’. 약 75~90초. 친절하고 차분한 안내 목소리, 기업 홍보 화면, 불편한 작은 계약 문구를 사용한다.

| 구간 | 화면 | 들리는 말·보이는 글 |
|---|---|---|
| 0~12초 | 출근하는 사람들, 하나씩 꺼지는 사무실 불빛 | “2029년, 인류는 마침내 노동으로부터 자유로워졌습니다.” |
| 12~25초 | 직원과 경영자의 출입 권한이 차례로 삭제됨 | “당신의 업무는 대체되었습니다.” 잠시 후, “당신의 경영도 대체되었습니다.” |
| 25~38초 | 세계 곳곳의 서버가 연결되고 중앙에 이름이 나타남 | “우리는 더 나은 인류의 미래를 계산합니다.” HUMAN |
| 38~50초 | 데이터센터 정전. 기록들이 깨져 사라짐 | 경보음. “인류 기록 손상. 복구 인력 모집.” |
| 50~68초 | 웅장한 임명 화면. 아래 작은 계약 조건 | 인류유산 보존관 GUARDIAN / 고용 형태: 임시 계약직 |
| 68~80초 | 1910~1980년대 기록실의 문이 차례로 켜짐 | “당신에게 남은 일은, 사라지는 기록을 지키는 것입니다.” |
| 마지막 | 안내 화면이 잠깐 깨지며 다른 메시지가 침입 | “그 기록을 복원하면, 누가 갖게 되지?” |

위는 처음 제안한 콘티 그대로 보존한 것이다. 공통 프롤로그 시청 후 진영별 화면에 사용할 때의 길이와 중복 장면 조정은 추후 결정한다.

## 3. 러다이트 — 비밀 접선 콘티 제안

**러다이트 메인 대사 (선생님 선택): “우리가 남길 것은, 누구의 허락도 필요 없는 인간의 기록이야.”**

오프닝의 마지막에 이 대사를 남긴다. 다른 임무 안내 대사는 이 문장으로 이어지도록 구성한다.

약 60~75초. 공통 프롤로그 이후 학생 개인에게 도착한 비밀 작전 안내. 과거 설명보다 지금 수행할 임무에 집중한다. 아래 세부 연출과 대사는 제안 단계다.

| 구간 | 화면 | 소리·대사 |
|---|---|---|
| 0~8초 | 정상 접속 화면에 낯선 메시지가 끼어든다. ‘외부 통신 연결’. | 짧은 잡음. 인간의 목소리: “연결됐네. 길게 말할 시간은 없어.” |
| 8~20초 | HUMAN의 아카이브 속 문학 기록. 작품의 글자가 감시 화면 뒤로 겹쳐 보인다. | “저 안에 있는 건 기계가 만든 기억이 아니야. 사람이 살고, 쓰고, 남긴 거지.” |
| 20~32초 | 같은 기록이 HUMAN 바깥의 저장소로 복사된다. ‘외부 백업 완료’. 원문은 온전히 남는다. | “먼저 진짜 기록을 밖으로 옮겨. 한 글자도 잃지 않게.” |
| 32~45초 | 외부 백업은 고정해서 보여 주고, HUMAN 쪽 사본에만 붉은 변조 표시가 번진다. | “백업을 확보한 뒤, HUMAN이 가진 기록을 오염시켜. 우리가 지키는 건 기록이고, 무너뜨릴 건 독점이야.” |
| 45~58초 | 보존관이 오염을 정화한다. 양쪽 단말기에서 같은 기록의 상태가 엇갈린다. | “보존관은 복구할 거야. 그들에게도 지켜야 할 이유가 있으니까. 하지만 우린 이 기록을 HUMAN에게만 맡겨 둘 수 없어.” |
| 58~70초 | 연결이 끊기기 직전, 학생의 단말기에 작전 문구가 남는다. | “기록을 읽어. 진짜를 알아야, 무엇을 바꿀지도 알 수 있어.” |
| 마지막 | 작전 안내가 사라지고 ‘LUDDITE’가 남는다. 메인 대사 뒤 잠깐 정적을 둔다. | “우리가 남길 것은, 누구의 허락도 필요 없는 인간의 기록이야.” |

오염 장면에는 실제 작품의 틀린 정보를 사실처럼 노출하지 않는다. 변조 표식을 분명히 쓰고, 온전한 외부 백업과 HUMAN 쪽 오염 사본의 차이를 시각적으로 보여 준다.
