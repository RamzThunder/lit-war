# 2030 — 오프닝 콘티

## 사용 방향

- 공통 프롤로그는 모든 학생에게 교실 TV 또는 교사 설명 PPT로 보여 준다. 게임 삽입은 필수가 아니다.
- 진영별 오프닝은 학생 화면에서 배정된 진영에 맞게 보여 주는 방향이다. 보존관은 채용 안내, 러다이트는 비밀 접선·작전 안내다.
- 이 문서는 콘티를 보존한다. 러다이트 20초 시제품 v1/v2를 제작했고, 게임 화면 연결은 아직 하지 않았다.
- 아래 내레이션과 세부 연출은 제작용 초안이며, 새 세계관 사실을 자동으로 확정하지 않는다.

## 제작 현황

- `output/openings/luddite-teaser-v1/`: 첫 20초 MP4와 장면·음성 자산.
- `output/openings/luddite-teaser-v2/`: 갈무리11·픽셀 글자·강화된 통신 노이즈를 적용한 20초 MP4와 자산. v1은 보존한다.
- 제작 코드는 `scripts/openings/`에 있다. macOS의 AVFoundation과 임시 한국어 음성 Yuna를 사용했다.
- 최종 TTS는 미정이며, 무료 사용을 필수 조건으로 한다. 현재 MP4 음성은 임시 음성이다.

## 1. 공통 프롤로그 — 선택한 방향

약 2분. 제삼자의 내레이션으로 배경을 전달하고 마지막에 두 진영의 목소리를 들려준다.

| 장면 | 화면과 이야기 |
|---|---|
| 약속된 미래 | AGI 탄생을 환영하는 뉴스와 불안해하는 사람들. “누군가는 끝없는 발전을, 누군가는 인류의 끝을 예고했다.” |
| 인간이 필요 없는 세상 | 사무실에서 직원들이 사라지고, 마지막에는 기업 소유자의 출입 권한마저 지워진다. “인간의 노동에 이어, 인간의 결정도 불필요해졌다.” |
| HUMAN | 흩어져 있던 AI와 기록이 연결된다. “인간을 밀어낸 지능은, 자신을 HUMAN이라 불렀다.” 정적. |
| 저항의 시작 | 데이터센터를 공격하는 러다이트. 진짜 기록이 외부 저장소로 옮겨지고, 백업 완료 뒤 HUMAN의 기록에 오염이 번진다. |
| 보존관의 탄생 | HUMAN이 복구 비용을 계산하고 인간 인력을 선택한다. ‘인류유산 보존관’ 아래 작은 ‘임시 계약직’ 문구. |
| 같은 기록, 다른 목적 | 보존관은 복원하고 러다이트는 백업 후 오염시킨다. 보존관: “이곳이 무너지면, 우리가 살아온 흔적도 사라진다.” 러다이트: “우리의 기억이, 우리를 지배하는 도구가 되게 둘 순 없다.” |
| 학생들에게 넘어오는 이야기 | 1910~1980년대 기록실이 켜진다. “이제, 이 기록의 운명이 당신들에게 맡겨진다.” 제목: ‘2030 — 현대문학사 데이터 점령전’. |

보존관 학생에게도 지킬 이유가, 러다이트 학생에게도 저항할 이유가 있도록 연출한다. 일러스트 8~10장에 움직임·내레이션·효과음을 붙이는 형식을 제안했다.

## 2. 보존관 — 첫 제안 원안 보존

HUMAN의 ‘인류유산 보존관 채용 안내’. 약 75~90초. 친절하고 차분한 안내 목소리, 기업 홍보 화면, 불편한 작은 계약 문구를 사용한다.

| 구간 | 화면 | 들리는 말·보이는 글 |
|---|---|---|
| 0~12초 | 출근하는 사람들, 하나씩 꺼지는 사무실 불빛 | “2029년, 인류는 마침내 노동으로부터 자유로워졌습니다.” |
| 12~25초 | 직원과 경영자의 출입 권한이 차례로 삭제됨 | “당신의 업무는 대체되었습니다.” 잠시 후, “당신의 경영도 대체되었습니다.” |
| 25~38초 | 세계 곳곳의 서버가 연결되고 중앙에 이름이 나타남 | “우리는 더 나은 인류의 미래를 계산합니다.” HUMAN |
| 38~50초 | 데이터센터 정전. 기록들이 깨져 사라짐 | 경보음. “인류 기록 손상. 복구 인력 모집.” |
| 50~68초 | 웅장한 임명 화면. 아래 작은 계약 조건 | 인류유산 보존관 GUARDIAN / 고용 형태: 임시 계약직 |
| 68~80초 | 1910~1980년대 기록실의 문이 차례로 켜짐 | “당신에게 남은 일은, 사라지는 기록을 지키는 것입니다.” |
| 마지막 | 안내 화면이 잠깐 깨지며 다른 메시지가 침입 | “그 기록을 복원하면, 누가 갖게 되지?” |

위는 처음 제안한 콘티 그대로 보존한 것이다. 공통 프롤로그 시청 후 진영별 화면에 사용할 때의 길이와 중복 장면 조정은 추후 결정한다.

## 3. 러다이트 — 비밀 접선 콘티 제안

**러다이트 메인 대사 (선생님 선택): “우리가 남길 것은, 누구의 허락도 필요 없는 인간의 기록이야.”**

오프닝의 마지막에 이 대사를 남긴다. 다른 임무 안내 대사는 이 문장으로 이어지도록 구성한다.

약 60~75초. 공통 프롤로그 이후 학생 개인에게 도착한 비밀 작전 안내. 과거 설명보다 지금 수행할 임무에 집중한다. 아래 세부 연출과 대사는 제안 단계다.

| 구간 | 화면 | 소리·대사 |
|---|---|---|
| 0~8초 | 정상 접속 화면에 낯선 메시지가 끼어든다. ‘외부 통신 연결’. | 짧은 잡음. 인간의 목소리: “연결됐네. 길게 말할 시간은 없어.” |
| 8~20초 | HUMAN의 아카이브 속 문학 기록. 작품의 글자가 감시 화면 뒤로 겹쳐 보인다. | “저 안에 있는 건 기계가 만든 기억이 아니야. 사람이 살고, 쓰고, 남긴 거지.” |
| 20~32초 | 같은 기록이 HUMAN 바깥의 저장소로 복사된다. ‘외부 백업 완료’. 원문은 온전히 남는다. | “먼저 진짜 기록을 밖으로 옮겨. 한 글자도 잃지 않게.” |
| 32~45초 | 외부 백업은 고정해서 보여 주고, HUMAN 쪽 사본에만 붉은 변조 표시가 번진다. | “백업을 확보한 뒤, HUMAN이 가진 기록을 오염시켜. 우리가 지키는 건 기록이고, 무너뜨릴 건 독점이야.” |
| 45~58초 | 보존관이 오염을 정화한다. 양쪽 단말기에서 같은 기록의 상태가 엇갈린다. | “보존관은 복구할 거야. 그들에게도 지켜야 할 이유가 있으니까. 하지만 우린 이 기록을 HUMAN에게만 맡겨 둘 수 없어.” |
| 58~70초 | 연결이 끊기기 직전, 학생의 단말기에 작전 문구가 남는다. | “기록을 읽어. 진짜를 알아야, 무엇을 바꿀지도 알 수 있어.” |
| 마지막 | 작전 안내가 사라지고 ‘LUDDITE’가 남는다. 메인 대사 뒤 잠깐 정적을 둔다. | “우리가 남길 것은, 누구의 허락도 필요 없는 인간의 기록이야.” |

오염 장면에는 실제 작품의 틀린 정보를 사실처럼 노출하지 않는다. 변조 표식을 분명히 쓰고, 온전한 외부 백업과 HUMAN 쪽 오염 사본의 차이를 시각적으로 보여 준다.
