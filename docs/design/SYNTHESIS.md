# 화면 디자인 시안 3종 종합 (Claude · Gemini · GPT)

같은 [요청문](SCREEN-DESIGN-PROMPT.md)으로 받은 세 시안을 비교하고, 화면마다 가져올 것을 골라 하나의 방향으로 묶은 문서입니다.

| 시안 | 파일 | 한 줄 평 |
|---|---|---|
| Claude | [claude-v1/](claude-v1/README.md) | 가장 덜어낸 안. 실제 게임 화면을 넣었고 학생 화면 게임 비율 86% |
| Gemini | [gemini-v1/index.html](gemini-v1/index.html) | 정보 문장이 가장 친절함. 공격 중계 한 줄 제목이 명확. 게임 규칙 오류가 가장 많음 |
| GPT | [gpt-v1/index.html](gpt-v1/index.html), [개요 이미지](gpt-v1/overview.png) | 가장 '관제 콘솔'다움. 교사 화면 구조가 가장 탄탄. 없는 데이터를 많이 지어냄 |

## 1. 셋이 똑같이 고른 것 → 확정해도 되는 것

- 어두운 바탕, 테두리 상자 대신 **면의 밝기 차이**로 영역 구분
- 의미 색은 **보존관 파랑 · 러다이트 빨강 · 경보색 1개**만
- **갈무리11은 숫자·코드·시스템 표기에만**, 문장은 고딕(Pretendard 또는 Noto Sans KR)
- 시대 칸은 통째로 칠하지 않고 **왼쪽 띠 + 라벨 색**으로 점령 표시
- **시각이 붙은 관제 로그**, `HUMAN ARCHIVE …` 같은 작은 시스템 줄
- TV에는 버튼 없음, 학생 화면은 소개 문구를 없애고 게임을 크게
- 학생 화면은 **진영별로 배치는 같고 겉모습만 다르게**

세 모델이 따로 같은 결론에 닿았으므로, 위 항목은 더 논의하지 않고 디자인 체계로 확정하는 것을 추천합니다.

## 2. 셋이 갈린 것 → 추천

| 항목 | Claude | Gemini | GPT | 추천 |
|---|---|---|---|---|
| 경보색 | 보라 `#c9a2ff` | 주황 `#F59E0B` | 노랑 `#F0C65D` | **노랑 계열(GPT)**. 2:1이고, '경고'로 바로 읽히며 HUMAN 홍보의 노랑과도 이어진다. 단 공격(감전 칸)에는 쓰지 말고 경보·오염 전용으로 둔다 |
| 보존관 학생 화면 바탕 | 어두운 바탕 + 파랑 선 | **밝은 흰/민트 틀** | **밝은 틀** | **밝은 틀(Gemini·GPT)**. 오프닝의 밝은 HUMAN 홍보와 이어지고, 교실에서 누가 어느 진영인지 멀리서도 구분된다. 게임 지도는 원래 색 그대로 |
| 학생 HUD 위치 | 위·아래 얇은 띠(지도 86%) | 띠 + 지도 위 칩(83%) | 전부 지도 위에 띄움(92%) | **얇은 띠(Claude)** + 가운데 위 **이벤트 칸 하나(GPT)**. GPT 방식은 숫자상 넓지만 미션 카드·버튼 묶음이 지도 왼쪽 위를 가린다 |
| 교사 화면 구조 | 위 조작 띠 + 명단 + 오른쪽 열 | 위 조작 띠 + 3열 | **왼쪽 조작 열** + 가운데 명단 + 오른쪽 사건 열 | **GPT 구조 + Claude 명단**. 조작 버튼이 항상 같은 자리(왼쪽)에 세로로 있어 찾기 쉽다. 명단은 GPT처럼 '외 9명'으로 접지 말고 Claude처럼 30명이 스크롤 없이 보이게 |
| TV 맨 위 | 점수–시간–점수 한 줄 | 시간 헤더 + 줄다리기 띠 | 시간·점수·인원 세 칸 | **Claude 한 줄 + GPT의 보조 문구**(`보존관 우세 +135`, 진영별 접속·점령 수). 교실 뒤에서는 큰 숫자 세 개가 가장 잘 읽힌다 |
| 공격 중계 화면 | 실제 게임 화면 + 큰 초 | 한 줄 제목 + 자리 표시 | 대결 카드 + 결과 카드 | **실제 게임 화면(Claude) + 한 줄 제목(Gemini: `[러다이트] 민준 ▶ 침입 ▶ [보존관] 서연의 기록실`) + 결과 카드(GPT)**. 게임 화면 중계는 이미 교사 화면에 구현되어 있어 자리 표시가 필요 없다 |
| 입장 대기 | 큰 QR + 이름 칩 | 주소·QR·진영 카드 | QR 카드 + 인원 숫자 + 안내 | **Claude 배치 + GPT 아래 안내**(`선생님이 오프닝을 시작하면 각자 기기에서 영상이 나와요`). 이름 칩은 학생이 '나 들어왔다'를 TV에서 확인할 수 있어 남긴다 |
| 시대 칸 부가 정보 | 점령 팀만 | `SEC-01` 코드 + 상태 점 | 시대 별칭(`개화기 기록실`) + 상태 문장 | **시대 별칭은 채택하되 실제 데이터로**. GPT의 `복원률 82%`, `권한 충돌 1건`은 게임에 없는 값이다. 별칭은 [wiring.js](../../src/prototype/minigames/wiring.js)의 키워드에서 뽑고 선생님이 검수 |

## 3. 각 시안에서 따로 가져올 좋은 아이디어

- **GPT · 접전 표시**: 점수 차가 작으면 `접전`으로 표시(지금은 완전 동점만 `동점`). 표시만 바꾸는 것이라 규칙은 그대로다. 기준값은 정해야 한다(예: 10점 이하).
- **GPT · 이벤트 칸 하나**: 학생 화면 가운데 위 한 자리를 오염 경보와 공격 배너가 번갈아 쓴다. 알림이 여기저기 뜨지 않는다.
- **GPT · 퇴장은 `⋯` 메뉴 안에**: 명단에 빨간 퇴장 버튼이 30개 늘어서지 않고, 실수로 누를 일이 줄어든다.
- **GPT · 공통 창 틀**: 미니게임 14종·수리·방해 공작·함정·미끼 창이 제목줄·본문·하단 조작부를 공유하고 본문만 바꾼다.
- **GPT · 로그 문장 구조**: 굵은 사건 이름(`러다이트 침입`, `정화 완료`) + 다음 줄에 상세 내용. TV에서 훑어 읽기 좋다.
- **Gemini · 상호작용 안내의 E 키를 진영색으로**: 작은 차이로 진영 정체성을 준다.
- **Gemini · 행동 버튼 숫자키 1/2/3**: 지금 게임에는 없는 단축키다. 넣는다면 키보드로 방해 공작·공격·함정을 바로 쓸 수 있다(새 기능이므로 선택 사항).
- **Claude · 실제 게임 캡처, 큰 남은 초, 이름 칩, 지도 비율 수치 근거**.

## 4. 시안에 섞여 있는 게임 규칙 오류 (구현 때 따라가면 안 됨)

| 시안 | 시안 내용 | 실제 규칙 |
|---|---|---|
| Gemini | 감전 `5회 시 강제 퇴출` | 5회는 **공격 한 번에 넣을 수 있는 최대 감전 수**. 퇴출 없음 |
| Gemini | SPACE = `감전 방어` / `회피·견제` | SPACE는 **공격자만** 쓰는 감전. 방어자는 도망만 친다 |
| Gemini | `🪤 감전 함정 설치` | 함정은 **미끼 단말기**. 러다이트가 고장 내려 하면 실패하고 반격 공격이 들어간다 |
| Gemini · GPT | 오염이 `발표 연도`·`주인공 이름`을 바꿈 | 오염은 기록의 **시대 또는 작가** 칸만 바꾼다 |
| Gemini · GPT | 진행 중에 `🎬 오프닝 다시 재생` 버튼 | 서버가 진행·멈춤 중에는 오프닝을 거부한다. **시작 대기·오프닝·종료 상태에서만** 보여야 한다 |
| Gemini | 오프라인 학생에게도 퇴장 버튼 | 퇴장은 접속 중인 학생에게만 의미가 있다 |
| GPT | `복원률 82%`, `권한 충돌 1건`, 시대 별칭 | 게임에 없는 데이터. 별칭은 실제 키워드로 바꿔야 한다 |
| GPT · Gemini | 공격 중계 화면이 자리 표시 | 실제 중계(Phaser)가 이미 교사 화면에 있다. 그대로 TV에 쓰면 된다 |

## 5. 정해야 할 것 (추천안 포함)

Gemini가 짚은 4개를 앞에 두고, 세 시안에서 나온 나머지를 합쳤습니다.

| # | 결정 | 지금 코드 | 추천 |
|---|---|---|---|
| 1 | **동시 공격 여러 건일 때 TV** | 교사 화면은 새 공격이 시작되면 바로 그쪽으로 넘어가고, 끝나면 3초 결과 후 다음 건으로 | **1건 집중 + 대기열**(셋 다 동의). 단 TV에서는 새 공격이 와도 보던 건을 끊지 않고, 끝난 뒤 대기열 순서대로. 한 건이 최대 15초라 오래 기다리지 않는다 |
| 2 | **학생 화면의 오염 경보 연출 강도** | 학생 화면에 알림 문구만 | **가운데 위 이벤트 칸 + 시작·끝에 0.5초 짧은 지지직**. 미니게임 중 시야를 가리는 상시 글리치는 넣지 않는다 |
| 3 | **터치 조작 전환 기준** | 이미 `pointer: coarse`이거나 게임 화면을 처음 터치하면 조이스틱 표시(주소 `?touch`로 강제 가능) | **지금 방식 유지**. 제미나이 권장과 같다. 터치 크롬북에서 키보드로만 하는 학생에게도 처음 터치 전까지는 안 보인다 |
| 4 | **끊긴 학생 표시와 명단 정렬** | 접속 중 → 미션 많은 순 정렬, 끊기면 아래로 내려가며 회색 | **진행 중에는 순서를 고정(가나다순)하고 제자리에서 회색 + 명단 위에 `끊김 2명`**. 미션 수가 바뀔 때마다 줄이 움직이면 선생님이 이름을 찾기 어렵다. 위로 끌어올리는 경고는 너무 시끄럽다 |
| 5 | TV를 교사 화면과 분리할지 | 같은 화면에서 TV 모드 전환 | **분리**(세 시안 모두 분리를 전제). TV는 조작 권한 없는 보기 전용 링크로 열 수 있게 할지(비밀번호 없이)도 함께 정한다 |
| 6 | 경보색 | 보라(교사 화면 현재 구현) | **노랑 계열**로 통일 |
| 7 | 보존관 학생 화면 밝은 틀 | 어두움 | **밝은 틀** 채택 |
| 8 | 접전 기준 | 완전 동점만 `동점` | 표시용 `접전` 도입 여부와 기준 점수 |
| 9 | 시대 별칭 | 없음 | 쓸지, 쓴다면 문구를 선생님이 검수 |
| 10 | 행동 단축키 1/2/3 | 없음 | 넣을지(새 기능) |
| 11 | 글꼴 불러오기 | 시안은 CDN | 학교망이 CDN을 막을 수 있으니 **글꼴 파일을 게임에 직접 포함**(둘 다 OFL) |

## 5-1. 결정된 것 (2026-11-20)

- **접전 표시: 채택.** 한 시대에서 두 팀 점수 차가 **10점 이하**(미션 하나 차이)면 점령 팀 색은 유지하고 노란 `접전` 표시를 붙인다. 표시만 바꾸며 서버 규칙은 그대로. 완전 동점은 지금처럼 `동점`.
- **시대 별칭: 폐기.** 시대 칸에는 연도와 점령 상태만 둔다.
- **행동 단축키: 채택, 구현 완료.** `1` 방해 공작, `2` 실시간 공격(2를 두 번 눌러야 출발, 첫 번째에는 "2를 한 번 더 누르면 출발해요" 안내와 버튼 깜박임), `3` 함정(보존관만). 입력 중·창 열림·오프닝 중에는 꺼진다. 코드: [bindShortcuts.js](../../src/prototype/ui/bindShortcuts.js)

## 6. 다음 단계 제안

1. 위 5번 표에서 결정을 받는다.
2. 결정을 반영한 **통합 시안 v2**를 한 벌 만든다(TV 3장, 교사 1장, 학생 2장).
3. TV → 교사 → 학생 순서로 실제 화면에 적용한다. TV는 기존 교사 화면의 데이터를 그대로 쓰므로 가장 빨리 바꿀 수 있다.
