07 / 공통 디자인 체계 · 사용한 것과 뺀 것

DESIGN SYSTEM / OPEN QUESTIONS

색상·타이포그래피

  • 배경·패널: #080F19 / #111C29 / #1D2D40. 정보 영역은 면의 명도 차이로 구분하고, 모든 패널에 테두리를 두르지 않습니다.
  • 보존관: #4B9EFF. 러다이트: #FF626C. 경보: #F0C65D. 점령, 점수, 경보처럼 의미가 있을 때만 씁니다.
  • 고딕체: Noto Sans KR. 본문 14–18px, 보조 12–14px, TV 본문은 시안에서도 최소 24px로 고정합니다. 교사 표의 예시 수치는 축소 프리뷰 기준입니다.
  • 시스템 숫자·짧은 라벨: Galmuri11 우선, 대체 폰트 IBM Plex Mono. 큰 타이머·방 코드·연도·점수에만 제한합니다.

간격·선·상태

  • 간격: 4px 기준, 주요 간격은 8 / 12 / 16 / 24 / 32px. 패널 내부는 16–24px 여백으로 호흡을 확보합니다.
  • 모서리: 4–10px. 경보·시스템 패널만 얇은 1px 선을 쓰고, 시대 칸을 팀 색으로 채우지 않습니다.
  • 상태: 접속 정상=작은 점, 진행 중=텍스트 칩, 접전=황색 점, 오염=황색 라벨+문장, 미점령=중성 회색. 색만으로 상태를 구분하지 않습니다.
  • 학생 진영 차이: 정보 위치는 고정. 보존관은 밝은 공식 단말기 셸, 러다이트는 어두운 우회 접속 셸로 표면과 문구만 차별화합니다.

상황판다움을 위해 쓴 요소

  • 세션 코드·섹터·기록실·복원/접속 상태·KST 타임스탬프 등 시스템 표기를 최소한으로 사용했습니다.
  • 8개 시대를 동일 크기의 기록실 노드로 묶어 하나의 보관소 지도로 읽게 했습니다. 팀 색은 소유 표식과 점수에만 노출됩니다.
  • 최근 이벤트를 시간순 로그로 쌓고, 공격 시에는 게임 지도 영역을 크게 확장하는 별도 중계 상태를 뒀습니다.
  • 오염·공격·점령 변경 때만 황색 신호·짧은 점멸을 추가합니다. 학생 상단 이벤트 슬롯은 오염 경보와 공격 배너가 교대로 차지합니다. TV 오프닝 시청 중은 완료 n/m명 안내, 멈춤은 중앙 상태 오버레이, 종료는 시대별 최종 점령 결과로 같은 레이아웃을 재사용합니다.

일부러 뺀 요소

  • 상시 스캔라인·노이즈·격자 오버레이·뉴스 티커·반복 점멸은 제외했습니다. 게임 지도 자체에만 필요한 픽셀 격자를 남겼습니다.
  • 각 시대 전체를 파랑/빨강으로 칠하거나 모든 정보를 굵은 카드 테두리로 나누지 않았습니다.
  • 장식용 그래프·중복 점수·불필요한 랭킹·인물 얼굴·큰 로고 애니메이션은 제외했습니다.
  • TV는 조작 버튼을 두지 않았고, 학생 화면은 상단 소개 문구와 별도 설명 영역을 없애 게임 지도를 넓혔습니다.
