# 요청: 「2030 현대문학사 데이터 점령전」 화면 3종 디자인 시안

> 다른 AI·디자인 도구나 함께 의견을 낼 사람에게 그대로 붙여 넣는 요청문입니다. 받은 시안은 `docs/design/<이름>/`에 모아 비교합니다. Claude 시안은 `docs/design/claude-v1/`에 있습니다.

## 1. 게임 소개 (배경 지식)
- 중학교 국어 수업용 실시간 교실 게임. 한 반 최대 30명이 각자 크롬북으로 접속하고, 교사는 노트북과 교실 TV를 쓴다.
- 세계관: 2029년 AI가 지적 노동을 대신하면서 사람의 기록이 사라지는 2030년. 거대 기업 시스템 **HUMAN**이 인류의 기록을 관리한다.
- 두 진영이 1910~1980년대 한국 현대문학 기록을 두고 겨룬다.
  - **인류유산 보존관 (파랑)**: HUMAN에 고용되어 기록을 복원·정화한다. HUMAN의 밝은 홍보 톤(민트·노랑)과 연결된다.
  - **러다이트 (빨강)**: HUMAN의 기록 독점에 저항해 원본을 빼돌리고 사본을 오염시킨다. 어두운 해킹 단말기 톤과 연결된다.
- 학생은 탑다운 픽셀 게임 속 '자기 기록실'을 돌아다니며, 시대별 단말기 8개에서 문학 미니게임(작가-작품 연결, 발표 순서 맞추기 등)을 풀어 그 시대에 팀 점수를 쌓는다. 시대마다 점수가 높은 팀이 그 시대를 '점령'한다.
- 수업 흐름: 교사가 방 열기 → 학생 입장(코드/QR) → 진영별 오프닝 영상 → 게임 진행(보통 30~45분) → 종료.
- 기존 아트 자산: 픽셀 아트 게임 화면과 오프닝 영상. 영상 자막과 숫자에는 픽셀 글꼴 **갈무리(Galmuri11)**를 쓴다.

## 2. 디자인 원칙 (꼭 지킬 것)
- **'2030년 데이터 관제 시스템의 실시간 상황판'**처럼 보여야 한다. 일반 관리자 대시보드나 학습지 느낌은 피한다.
- 그렇다고 장식으로 채우지 않는다. 이전 시안은 모든 요소에 두꺼운 테두리 상자를 두르고, 시대 칸을 팀 색으로 통째로 칠하고, 강조색을 다섯 가지나 쓰고, 속보 자막·격자·줄무늬를 겹쳐서 **조잡하다**는 평을 받았다.
  - 영역은 여백·정렬·약한 바탕 차이로 나눈다.
  - 색은 의미가 있는 곳에만 쓴다: 팀 파랑/빨강 + 경보용 강조색 1개.
  - 픽셀 글꼴은 큰 숫자·제목 등 '시스템 표시'에만 쓰고, 문장은 읽기 쉬운 고딕체로 쓴다.
  - 같은 정보를 두 번 보여 주지 않는다.
- '상황판다움'은 다음 같은 절제된 요소로 표현해 본다(전부 쓸 필요는 없음, 제안 환영):
  - 시스템 용어와 표기: 섹터·기록실·단말기·복원률·신호, 실시간 시각 표시(타임스탬프), 상태 표시등(접속/연결/경보)
  - 관제 로그처럼 쌓이는 실시간 소식
  - 시대 8칸을 하나의 '기록 보관소 지도'로 읽히게 배치
  - 사건이 생길 때만 잠깐 나타나는 효과: 오염 경보 때 신호 간섭·노이즈, 점령이 바뀔 때 깜박임 등(평소에는 조용하게)
  - 진영별 시점 차이: 같은 정보라도 보존관 화면은 HUMAN 공식 시스템, 러다이트 화면은 해킹한 단말기처럼
- 한국어 UI. 학생은 중학생이므로 문구는 짧고 쉽게 쓴다.
- 인물 얼굴을 그리지 않는다(세계관 아트 원칙). UI에는 사람 얼굴 이미지를 쓰지 않는다.

## 3. 화면별 요구사항

### 3-1. TV 화면 (교실 앞 TV, 1920×1080 고정, 조작 없음)
- 용도: 반 전체가 교실 뒤에서도 보는 '전황판'. 버튼이 하나도 없다. 가장 작은 글씨도 24px 이상.
- 상태별로 화면이 바뀐다. 각 상태의 시안이 필요하다.
  1. **입장 대기**: 큰 방 코드, 접속 주소, QR 코드, 지금 들어온 인원(진영별)
  2. **오프닝 상영 중**: "오프닝 시청 중" 안내, 시청 완료 n/m명. 영상은 학생 기기에서 재생되고 TV에는 나오지 않는다.
  3. **진행 중(기본 화면)**
     - 남은 시간(가장 크게)
     - 두 진영 총점과 우세 정도(줄다리기 막대 등)
     - 진영별 접속 인원, 점령한 시대 수
     - 시대 8칸(1910~1980년대): 점령 진영, 진영별 점수, 상태 표시(🧪 오염됨, 접전/동점, 비어 있음)
     - 실시간 소식: 침입·감전·점수 탈취, 바리케이드·단말기 고장, 미끼 심기·정화, 권한 획득
     - 늦게 온 학생을 위한 작은 입장 코드
  4. **오염 경보(1분 이벤트)**: 남은 초, "미끼·정화 점수 2배". 평소 화면 위에 잠깐 겹치는 형태
  5. **실시간 공격 중계**: 공격이 일어나면 화면 큰 부분을 차지한다. 픽셀 지도 위 두 학생의 움직임(게임 화면을 그대로 넣음), 공격자→방어자 이름과 진영, 15초 카운트다운, 감전 n/5회, 탈취 점수, 결과("○○ 승! 15점 탈취" / "완벽 회피!"). 여러 공격이 동시에 일어날 수 있다.
  6. **멈춤 / 종료**: 종료 때는 승리 진영, 시대별 최종 점령 결과, (선택) 활약한 학생

### 3-2. 교사용 화면 (교사 노트북, 1280~1440px, 마우스 조작)
- 용도: 수업 진행을 조작하고 학생 상황을 살피는 화면. TV와 따로 열어 두는 것을 전제로 한다(지금은 TV 모드 버튼으로 같은 화면을 전환해 쓴다).
- 필요한 기능
  - **방 열기**: 방 코드 입력 또는 '새 코드'(헷갈리는 글자를 뺀 6자리), 교사 비밀번호
  - **진행 조작**: 🎬 오프닝 재생 / 다시 재생, 수업 시간(1~90분), ▶ 시작(오프닝 중에는 전원 시청 완료 전까지 잠김), 기다리지 않고 시작, ⏸ 멈춤, ▶ 계속, ■ 종료, ↺ 초기화(점수·미션 0, 팀 유지), ⚠ 오염 경보 발동
  - 현재 상태(시작 대기·오프닝 상영·진행 중·멈춤·종료)와 남은 시간
  - **학생 명단(최대 30명, 진영별 2열)**: 이름, 접속 여부, 미션 수, 공격 중 표시, 오프닝 상태(⏳ 대기 / ⬇ 불러오는 중 40% / 👆 재생 버튼 대기 / ▶ 시청 중 / ✓ 완료 / ⚠ 오류), 퇴장 버튼
  - 진영 총점, 시대별 점령 현황, 실시간 소식
  - **오염 기록**: 어떤 작품의 어떤 칸이 가짜 값→진짜 값으로 바뀌었는지, 누가 누구 방에 심었는지, 정화 여부
  - **실시간 공격 중계**(여러 건이면 탭)
  - **학생 입장 안내 패널**: 큰 코드와 QR. 열고 닫을 수 있다.
  - 서버 오류나 안내는 눈에 띄는 알림으로 보여 준다.
- 원칙: 버튼이 많지만 지금 상태에서 누를 수 있는 것만 보이게 한다. 위험한 버튼(종료·초기화·퇴장)은 구분한다.

### 3-3. 학생 화면 (크롬북 위주: 1366×768, 키보드+터치패드, 일부 터치. 휴대폰·태블릿도 가능)
- 용도: 게임을 하는 화면. **게임 화면(탑다운 픽셀 지도)이 최대한 크게** 보여야 한다. 지금은 위아래 소개 문구 때문에 게임 창이 화면 높이의 약 58%밖에 안 된다.
- 게임 위나 주변에 들어갈 정보(HUD)
  - 내 진영 배지, 지금 있는 방(내 기록실 / 습격 중인 상대 기록실)
  - 남은 시간과 수업 상태(시작 대기·진행 중·멈춤·끝)
  - 미션 수, 다음 권한까지 남은 미션 수(5개마다 방해 공작, 10개마다 실시간 공격권)
  - 행동 버튼: 🛠 방해 공작(개수), ⚡ 실시간 공격(개수), 🪤 함정(보존관만)
  - 시대별 팀 점수/점령 현황(작게)
  - 상호작용 안내("E 기록 열기", "E 수리", "E 정화"), 짧은 알림 메시지
  - 실시간 공격 배너: 공격자/방어자 문구, 15초 카운트다운, 감전 횟수
  - 오염 경보 알림
  - 접속 상태, 방 코드, 접속 인원
  - 조작법(WASD/방향키 이동, E 상호작용, SPACE 감전, ESC 닫기). 터치 기기는 조이스틱과 상황별 버튼(기록 열기·정화·수리·감전)
- 게임 위에 뜨는 창(같은 디자인 체계 필요)
  - 교실 입장(방 코드·닉네임, QR로 들어오면 코드 자동 입력)
  - 단말기 미니게임 창(14종: 배선 연결, 주파수 맞추기, 키워드 기억, 오답 격추, 작가 신원 확인, 시대 분류, 연도순 책 꽂기 등)
  - 수리(연대순 카드 누르기), 방해 공작 대상 지도, 함정 지정, 미끼 심기/정화 창
  - 오프닝 영상 전체 화면, 불러오는 중 진행 막대, 시청 완료 후 대기 화면
- 원칙: **진영에 따라 바깥 틀의 인상을 다르게** 한다(보존관=HUMAN 공식 단말기, 러다이트=몰래 접속한 해킹 단말기). 단, 정보 배치와 조작 위치는 같게 해서 선생님이 한 번에 설명할 수 있게 한다. 768px 높이에서도 스크롤 없이 게임과 HUD가 모두 보여야 한다.

## 4. 결과물로 받고 싶은 것
1. 세 화면이 공유하는 디자인 체계: 색(값 포함), 글꼴과 글자 크기 단계, 간격, 모서리/선 규칙, 상태 표시 방식
2. 화면별 레이아웃 시안(가능하면 HTML/CSS 정적 시안 또는 이미지)
   - TV: 진행 중 화면 + 입장 대기 + 공격 중계
   - 교사: 진행 중 화면
   - 학생: 보존관·러다이트 각 1장(크롬북 1366×768)
3. '상황판다움'을 위해 쓴 요소와, 일부러 뺀 요소 목록. 이유도 짧게
4. 확신이 없거나 우리가 정해야 할 결정 사항 목록
