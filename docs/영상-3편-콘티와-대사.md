## 편집·반영 방법

- `- **C001**: 대사`처럼 식별자가 붙은 줄에서 **콜론 뒤의 문구만** 고치세요. C는 공통, G는 보존관, L은 러다이트입니다. 식별자를 바꾸거나 지우지 마세요.
- 각 항목은 하나의 문구입니다. 기존 여러 줄 대사는 항목도 나뉘며, 긴 하단 자막은 화면 너비에 맞춰 자동 줄바꿈합니다. 문서가 자동 줄바꿈되어 보이는 것은 괜찮지만, 항목 중간에 Enter를 넣지 마세요. 문구와 문장부호는 유지하며, 자동 줄바꿈 경계의 공백만 정리합니다.
- 반복 문구는 각 편의 ‘고정·반복 문구’에서 한 번만 편집합니다. 장면의 식별자 참조는 같은 문구를 가리킵니다.
- 대사는 아래 재렌더링 명령이 **이 문서에서 직접 읽습니다.** 저장만으로 기존 MP4가 바뀌지는 않습니다. 너무 길어진 문구는 화면 배치도 확인해야 합니다.
- **화면·상세 연출·시간**은 연출 지시입니다. 자유롭게 수정하되, 자연어를 자동으로 애니메이션으로 바꾸지는 않습니다. 이 부분을 수정했다면 해당 제작 코드에 반영한 뒤 재렌더링해야 합니다. 문서의 시간 숫자만 바꿔서는 영상 시간이 바뀌지 않습니다.
- 1910~1980년대 숫자, 진행률, 시험 번호처럼 계산으로 생성되는 표시도 코드 변경 대상입니다.

저장소 루트에서 검증 및 재제작:

```sh
python3 scripts/openings/storyboard.py check
python3 scripts/openings/storyboard.py render common
python3 scripts/openings/storyboard.py render guardian
python3 scripts/openings/storyboard.py render luddite
# 프레임 확인: python3 scripts/openings/storyboard.py preview guardian --at 75
# 세 편 모두: python3 scripts/openings/storyboard.py render all
# 음악·효과음이 있는 최종본 3편: python3 scripts/openings/score.py
```

macOS·Swift·설치된 Galmuri11 글꼴이 필요합니다. 먼저 문구·식별자를 검증한 뒤 선택한 최신 영상만 재제작합니다. 티저는 공통편 재제작 후 `sh scripts/openings/make-teaser.sh`로 별도 갱신합니다.

얼굴 비노출·무음 이해 원칙을 유지합니다. HUMAN의 ‘테러 집단’은 홍보 주체의 적대적 호칭이며 중립 명칭은 러다이트입니다. 보존관 광고는 비용 계산과 고용 조건을 숨기는 설정이며, 공통편 인간 대사는 그 속내를 드러냅니다.

공통 광고와 보존관 안내에는 **Future Loop**가 흐른다. 공통편은 TV가 꺼지는 67초부터 **Real Human theme – No Loop**가 원래 속도로 흐른다. 보존관편은 69초에 음악이 끊기고 화면 조정 뒤 73.65초에 안내 음악이 돌아온다. 러다이트편은 HUMAN 음악으로 시작해 4초에 잡음이 끼고, 붉은 로고가 자리 잡은 7초에 **Square Wave Assault**가 시작된다.

HUMAN 방송 타이틀에는 첨부 원본의 흰 심볼·워드마크·영문 부제를 하나의 이미지로 중앙 정렬한다. 작은 방송 표식에는 같은 원본에서 심볼만 잘라 사용한다. 러다이트는 끊긴 이중 조준환과 겹친 사선의 붉은 픽셀 심볼을 사용한다.
