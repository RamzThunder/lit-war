# 보존관 오프닝 v1 — 당신과 함께 만드는 더 나은 내일

83초 / 1280×720 / 24fps / H.264 / 무음. 공통편의 밝은 HUMAN 픽셀 광고와 같은 밝은 광고 톤에 보존관 전용 도서관 배경, 민트·노랑·코랄, 축포, 갈무리 글꼴을 사용한다.

HUMAN은 자신의 비용 계산을 공개하지 않는다. 대신 인간의 경험·공감·꼼꼼함을 칭찬하며 ‘인류의 이야기를 잇는 특별한 역할’로 보존관을 포장한다. 비용 비교와 임시 계약직 문구는 광고에서 제외한다. 세계관의 실제 고용 설정을 바꾸는 것이 아니라, 홍보 주체가 보여 주는 정보를 선택하는 연출이다.

| 시간 | 화면·움직임 | 화면 대사 |
|---|---|---|
| 0~8초 | 새로 그린 보존관 도서관과 축포. 새로운 무대가 열린다는 축하 카드. | “당신의 경험이, 모두의 내일을 밝힙니다!” |
| 8~18초 | 책 세 권이 차례로 등장. 마음을 움직인 글·함께 나눈 생각·오래 남은 기억. | “글 속의 마음을 헤아리고, 이야기를 나누는 힘.” → “그 소중한 경험을, 이제 모두를 위해 나눠 주세요!” |
| 18~28초 | 기록들이 떠 있고 일부에 물음표. 위기보다 회복 가능성을 강조. | “자칭 ‘러다이트’라는 테러 집단이, 소중한 문학 기록을 훼손했어요.” → “괜찮아요. 여러분과 함께라면 다시 이어 갈 수 있어요!” |
| 28~38초 | 별과 축포 속에 인류유산 보존관 직함 등장. | “당신의 꼼꼼함이, 모두의 기억을 지킵니다.” / “당신을 인류유산 보존관으로 초대합니다!” |
| 38~51초 | 자료와 복구할 기록을 나란히 제시. 김유정·1936년이 차례로 채워짐. | “작품과 작가, 시대를 천천히 살펴보세요.” → “자료를 읽고 빈칸을 채우면, 기록이 다시 살아나요!” |
| 51~62초 | 변조된 기록이 민트색의 올바른 기록으로 바뀌고 별이 반짝임. | “누군가 기록을 바꿔 놓았다면, 바른 내용을 찾아주세요.” → “틀린 정보를 바로잡는 일, 우리는 ‘정화’라고 불러요!” |
| 62~69초 | 1910~1980년대 책 카드가 차례로 켜짐. | “당신이 지킨 한 줄, 모두가 나눌 이야기” / “그 시대 사람들의 생각과 마음을, 내일로 이어 주세요!” |
| 69~69.8초 | 화면 전체가 가로 띠로 뒤틀리고 픽셀 노이즈·주사선이 발생한다. HUMAN 로고와 안내도 사라진다. | “신호 간섭 감지” |
| 69.8~72.8초 | 어두운 외부 신호가 화면을 완전히 점유한다. 노이즈는 가장자리에 남겨 질문은 읽을 수 있게 한다. | “외부 신호 수신 / HUMAN 채널 연결 끊김” / “그 기록을 복원하면, 누가 갖게 되지?” |

| 74~83초 | 다시 축포와 노란 카드. 경쾌하게 마무리. | “여러분의 활약을 기대합니다!” / “HUMAN과 함께, 이야기는 계속됩니다” / “준비되셨나요? 문학 기록실에서 만나요!” |

HUMAN은 상대를 “자칭 ‘러다이트’라는 테러 집단”으로 부른다. 이는 홍보 주체의 적대적 표현이며, 중립 설명과 러다이트 측 자기소개에는 기존 명칭을 유지한다. 복귀 안내는 73.65~77초, 약 3.35초 동안 표시한다.

## 제작

- 영상: `output/openings/guardian-v1/guardian-v1-no-voice.mp4`
- 코드: `scripts/openings/render-guardian-v1.swift`
- 새 배경: `assets/openings/guardian-v1/guardian-library.png`. 내장 image_gen으로 생성한 보존관 전용 픽셀 도서관. 책 모양 입구·청록색 서가·황금빛 천창으로 공통편 도시와 구분한다. 인물·얼굴·문자 없는 원본을 검수했다.
- 최종 생성 프롬프트 및 생성 출처: `assets/openings/guardian-v1/image-prompts.json`.
- 문학 예시는 게임 데이터 `src/prototype/minigames/wiring.js`의 김유정 「동백꽃」(1936)을 사용한다. 가짜 작가·연도는 노출하지 않는다.
- 실제 게임 UI 녹화가 아닌 역할 소개 애니메이션이다. 더빙·음악·게임 연결은 없다.
- `--stills` 검수 이미지는 `/tmp/guardian-preview-*.png`에 저장한다.

검수: 최종 MP4 83초·영상 1트랙·오디오 0트랙 확인. 12개 디코딩 프레임에서 적대적 호칭, 화면 조정, 73.65~77초 복귀 안내와 엔딩을 확인했다.
